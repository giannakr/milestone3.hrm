Connect HubSpot

Link Prova’s HubSpot private app

Create a HubSpot private app with CRM read scopes, then add the access token as HUBSPOT_ACCESS_TOKEN in Cursor Secrets for the published app. Do not paste the token into chat, commit it, or put it in client JavaScript.

Connection check

Checking…

  1. Create a HubSpot private app

    In HubSpot: Settings → Integrations → Private Apps → Create. Enable read scopes for crm.objects.contacts and crm.objects.deals (and account info if available).

  2. Copy the access token once

    Store it only in Cursor Secrets / the dashboard — never in this repo, .env committed to git, or a Slack/chat message.

  3. Bind the secret on the Cursor-hosted app

    Open Cursor → Cloud Agents → Secrets (or the publish dialog’s secrets list). Set HUBSPOT_ACCESS_TOKEN for the prova-careers app, then republish if prompted. GitHub Pages stays on sample data (no server secrets).
